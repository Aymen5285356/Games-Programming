# 🎮 Fantasy FPS RPG (Ursina Engine)

## 📌 Overview

Fantasy FPS RPG is a 3D first-person shooter game developed using Python and the Ursina Engine.
The project combines RPG mechanics with FPS gameplay, allowing the player to fight enemies using different weapons in a simple 3D world.

---

## 🚀 Features

### 🔫 Weapons System

* AK (automatic weapon with fast fire rate and recoil)
* Pistol (slower but more precise)
* Sword (close combat melee weapon)

### 🎯 Realistic Shooting

* Bullet spread system
* Camera recoil effect
* Raycast-based shooting
* Hit detection with visual impact effects

### 🧍 Enemy System

* Enemies with simple humanoid body (head + body)
* Basic AI (follow player)
* Health system and death handling

### 🖥️ Game Interface

* Dynamic crosshair (changes depending on weapon)
* Weapon display UI
* Main menu (Start / Quit / FPS toggle)

### 🖱️ Controls

* **WASD** → Move
* **Mouse** → Look around
* **Left Click** → Attack / Shoot
* **Right Click** → Zoom
* **1 / 2 / 3** → Switch weapons
* **ESC** → Back to menu / Quit

---

## 🛠️ Technologies Used

* Python 3
* Ursina Engine
* Panda3D (under the hood)

---

## ▶️ How to Run

```bash
pip install ursina
python main.py
```
